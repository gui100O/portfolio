# Guilherme Farias — Portfólio

> Código, design e ideias transformadas em experiências digitais.

Meu portfólio pessoal reúne um pouco do que venho construindo enquanto estudo **Análise e Desenvolvimento de Sistemas na FATEC**. Gosto de trabalhar na interseção entre desenvolvimento front-end e design visual: interfaces com personalidade, tipografia bem pensada e atenção aos detalhes.

## ✳ Projetos em destaque

### Weather Dashboard
Dashboard meteorológico para Cruzeiro, SP, com condições atuais e previsão por hora, consumindo dados da API Open-Meteo.

- **Tecnologias:** HTML, CSS, JavaScript, REST API
- **Repositório:** [gui100O/weather-dashboard](https://github.com/gui100O/weather-dashboard)

### Site Confeitaria
Site de confeitaria com uma identidade visual delicada e foco na apresentação dos produtos e da marca.

- **Tecnologias:** HTML, CSS, JavaScript
- **Repositório:** [gui100O/site-confeitaria](https://github.com/gui100O/site-confeitaria)

### archive.proj
Projeto de arquivo de filmes para organizar títulos, diretores e gêneros em uma aplicação conectada a banco de dados.

- **Tecnologias:** PHP, MySQL, HTML, CSS
- **Repositório:** [gui100O/archive.proj](https://github.com/gui100O/archive.proj)

## 🧰 Tecnologias e ferramentas

- **Front-end:** HTML5, CSS3, JavaScript
- **Back-end e dados:** PHP, MySQL
- **Outras ferramentas e estudos:** Python, Git e GitHub

## 🎨 Sobre o visual

O site combina uma base escura com cores vibrantes, formas geométricas e tipografia expressiva. A ideia é refletir meu interesse por design e desenvolvimento sem deixar a navegação e a leitura em segundo plano.

## 🚀 Executar localmente

O portfólio é feito com HTML, CSS e JavaScript, sem necessidade de instalar dependências.

1. Clone o repositório:
   ```bash
   git clone https://github.com/gui100O/portfolio.git
   ```
2. Entre na pasta:
   ```bash
   cd portfolio
   ```
3. Abra o arquivo `index.html` no navegador. Se preferir, use a extensão **Live Server** no VS Code.
